CREDENCIALES DE USUARIOS SEMILLA — DEV, TEST Y PRODUCCIÓN (DOCKER COMPOSE LOCAL)
==================================================================================

Este documento es la única fuente autoritativa de credenciales sembradas por los scripts/
migraciones de datos semilla del proyecto (migración 009, backend/scripts/seed_dev_users.py
y backend/scripts/seed_clients_aris_vaxthera.py). No incluye usuarios que solo existen como
fixtures de la suite de pruebas automatizadas (esos nunca se crean al levantar un ambiente real).

Desde spec 027, la migración 009 usa la MISMA contraseña fija para los usuarios semilla de rol
interno en los tres ambientes Docker Compose (Dev sin -p, Test -p sywork_test, Prod -p
sywork_prod), sin distinguir por FLASK_ENV. Desde spec 029, esa misma contraseña se reutiliza
para todos los usuarios adicionales sembrados por backend/scripts/seed_dev_users.py. Facilita
validar Test/Prod en local sin depender de una contraseña aleatoria que solo se imprime una vez
en el log del contenedor backend.

⚠️ ADVERTENCIA: antes de operar la Producción real en el servidor Ubuntu de destino con datos
de clientes reales, ESTA CONTRASEÑA DEBE ROTARSE manualmente (acción "Resetear contraseña"
como Admin, o endpoint PATCH /api/users/{id}/reset-password — ver specs/003-reseteo-contrasenas)
para todos los usuarios de rol interno de esta tabla. Nunca dejar la contraseña de este archivo
activa en un ambiente con datos reales.

La contraseña está codificada en base64 (NO es cifrado, es solo ofuscación visual).
Para decodificarla: echo "<valor>" | base64 -d   (o cualquier decodificador base64 estándar)

Comandos de referencia:
  docker exec sywork_backend alembic upgrade head
  docker exec sywork_backend python -m backend.scripts.seed_dev_users
  docker exec sywork_backend python -m backend.scripts.seed_clients_aris_vaxthera
